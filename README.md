## Problem Statement

This dashboard helps to analyze UPI transaction trends and user behavior. It enables stakeholders to understand:

Total transaction volume and value

Popular payment apps (PhonePe, GPay, Paytm, etc.)

Transaction success vs failure rates

Time-based trends (daily/monthly growth)

User activity patterns

By using this dashboard, businesses and analysts can identify growth trends, peak usage times, and potential issues in transactions, helping improve digital payment services.g


### Steps followed 

- Step 1 : Load data into Power BI Desktop, dataset is a csv file.
- Step 2 : Open power query editor & in view tab under Data preview section, check "column distribution", "column quality" & "column profile" options.
- Step 3 : Also since by default, profile will be opened only for 1000 rows so you need to select "column profiling based on entire dataset".
- Step 4 : It was observed that in none of the columns errors & empty values were present.
- Step 5 : Then created a new column using dax to group the age groups of people,also synced slicers on different pages and navigators.
- Step 6 : Inserted Bookmark and Page Navigators and published it to Power BI Service.
